# competitor-research — Claude.ai prompt template

Paste this entire block into a new Claude.ai chat.
Fill the [ ] fields before sending.

---

```
# Competitor research — product designer lens

## My context
I'm a product designer building my portfolio site (quang-studio).
Stack: Next.js, Tailwind CSS v4, Framer Motion.
Brand: minimal, sharp, Honeysuckle yellow (#e6fe7f) accent, Boldonse display font.
Applying for: [job title] at [company type e.g. B2B SaaS / consumer app / agency]

## Sites to analyse
1. [URL]
2. [URL]
3. [URL]
(Add up to 5)

## Analyse each site through a senior product designer's lens

### Visual design
- What is the design language? (typography, color, spacing, motion)
- What makes it distinctive vs generic?
- What would I steal, and why?

### UX patterns
- What is the primary user flow on the homepage?
- What interaction patterns are used? (scroll, hover, transitions, cursor)
- Where does the UX feel intentional vs accidental?

### Portfolio / case study structure
- How do they present work? (problem → process → outcome)
- What metrics or outcomes do they show?
- What do they leave out that weakens the story?
- How long does each case study take to read?

### Information architecture
- How is navigation structured?
- How do they handle mobile vs desktop differently?
- What content hierarchy decisions were made?

### Gaps & opportunities
- What does every site in this list do the same? (table stakes — must have)
- What is no one doing that would be memorable?
- Compared to my brand (Honeysuckle yellow, Boldonse, sharp/minimal), what would make
  my site stand out against these specifically?

## Output format
1. Comparison table: site × criteria (visual design / UX / case study / IA)
2. Gap analysis: what's missing across all of them
3. Three concrete design decisions I should make for quang-studio based on this
```

---

## When to use
- Before starting a new section or redesigning an existing one
- Before a job application — research that specific company's design aesthetic
- When feeling like the site looks too generic

## Screenshot tip
Screenshot Claude's output (especially the gap analysis + 3 decisions).
This becomes proof that you did research before designing.
